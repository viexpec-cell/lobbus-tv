# Lobbus TV · APK de teste

Ramo temporário com o APK assinado da **v0.2.0** para instalar na TV antes do primeiro release automático.

Na TV, no app **Downloader**, use:

`https://github.com/viexpec-cell/lobbus-tv/raw/apk/LobbusTV.apk`

Quando o GitHub Actions publicar os releases, o link fixo passa a ser
`https://github.com/viexpec-cell/lobbus-tv/releases/latest/download/LobbusTV.apk` e este ramo pode ser apagado.
